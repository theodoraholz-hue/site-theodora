# Como editar o site

## Edite somente um arquivo

Abra o projeto `site-quarto.Rproj` no RStudio e clique em:

```text
index.qmd
```

Todo o site está nesse arquivo:

- textos em português;
- textos em inglês;
- cores;
- formação;
- pesquisas;
- publicações;
- ensino;
- contatos;
- botão de idioma;
- botão de tema claro ou escuro.

O próprio arquivo possui comentários indicando cada seção.

## Visualizar o site

Dê dois cliques em:

```text
ABRIR-SITE.bat
```

Mantenha a janela preta aberta. Depois de editar o `index.qmd`, salve com
`Ctrl + S`. O navegador atualizará o site.

## Trocar a foto

Substitua:

```text
images/perfil.jpg
```

por outra foto, mantendo exatamente o mesmo nome.

## Importante

Não edite as pastas `_site` e `.quarto`. Elas são criadas automaticamente.
